PART 4: STEP-BY-STEP FOR CONNECTING REAL API ENDPOINTS (FASTAPI BACKEND)
--------------------------------------------------------------------------------

Once your client approves the mock data, you can connect the React tables to your
live PostgreSQL database by querying your FastAPI backend:

1. In the backend, define a router endpoint under `backend/app/routers/reports.py`:
```python
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session
from app.db.database import get_db

router = APIRouter(prefix="/api/reports", tags=["Reports"])

@router.get("/spares-stock")
def get_spares_stock_report(db: Session = Depends(get_db)):
    # Query your spares database table
    results = db.execute("SELECT id, name, category, compatible_loom, current_qty, min_level, unit_cost FROM spares_stock").fetchall()
    return [dict(r) for r in results]
```

2. In the React frontend, replace `MOCK_REPORTS_DATA` with a unified fetching
   hook inside `ReportsDashboard.jsx`:
```javascript
  const [reportRows, setReportRows] = useState([]);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    setLoading(true);
    fetch(`/api/reports/${activeReportId}`)
      .then(res => res.json())
      .then(data => {
        setReportRows(data);
        setLoading(false);
      })
      .catch(err => {
        console.error("Error loading report from FastAPI:", err);
        setLoading(false);
      });
  }, [activeReportId]);
```
