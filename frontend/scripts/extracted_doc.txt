Complete Formula & Calculation Reference Guide

3. Crimp % and Shrinkage %
These percentages measure how much the fabric contracts during weaving and processing. They are critical for accurate yarn ordering.
3.1 Bottom Warp Crimp %
Measures how much the warp yarn 'crimps' as it interlaces with the weft thread during weaving.
Bottom Warp Crimp % = (Warp Mtr - Fabric Mtr) / Fabric Mtr x 100
3.2 Shrinkage %
Measures how much the fabric shrinks after wet processing (washing, finishing, etc.).
Shrinkage % = (Fabric Mtr - Total Order Mtr) / Total Order Mtr x 100
3.3 Top Warp Crimp %
Same as bottom warp crimp, but calculated for the top beam in double-beam looms.
Top Warp Crimp % = (Top Warp Mtr - Fabric Mtr) / Fabric Mtr x 100
4. Reed Calculations
The reed is the comb-like device on the loom that spaces and separates the warp threads. Reed calculations determine the correct loom settings.

[TABLE]
Field | Formula | Example Value
Finished Reed | Input (based on fabric spec) | 80
Grey Reed | Onloom Reed + Grey Reed Add (4) | 76
Onloom Reed | Finished Reed - Reed Less (8) | 72
Finished Pick | Input (based on fabric spec) | 72
Onloom Pick | Finished Pick - Pick Less (4) | 68
Total Ends (Manual) | Finished Reed x Finished Width (inch) | 4,104
Total Ends (Auto) | Calculated automatically by formula | 4,560
Reed Space | Total Ends / Onloom Reed | 63.33 inches
Fabric Width (Grey) | Total Ends / (Onloom Reed + Grey Reed Add) | 60 inches
[END TABLE]

5. Design Ends Finding
Used to determine how many warp ends fit within a specific measurement in millimetres. Useful for design repeat planning.
Key conversions:
1 Inch = 25.4 MM
1 MTR = 39.37 Inches
Required Ends = (Required MM / 25.4) x Finished Reed
Example: Required MM = 3 → Required Ends = (3 / 25.4) x 80 = 10 ends

This table shows how many ends (threads) pass through each dent of the reed, and the resulting EPI (Ends Per Inch).

Reed Type | Dents per Inch | Ends per Dent | Total EPI
R3 | 1.5 | 64 | 96

[END TABLE]

EPI (Ends Per Inch) = Reed dents x Ends per dent — controls warp thread density in the fabric.
7. Warp Yarn Calculation (KGS)
This section calculates how many kilograms of warp yarn are needed for each colour, including a buffer for dyeing losses.
7.1 Required KGS Formula
REQ KGS = Ends x 1.094 / 1848 / Warp Count x Warp Mtr
Where:
1.094 = Conversion factor (yards to metres)
1848 = Hanks per kg constant for yarn count system
Warp Count = Yarn count (e.g. 20s, 40s)
Warp Mtr = Total warp metres required
7.2 With Dyeing Loss
With Dyeing Loss KGS = REQ KGS / (1 - Dyeing Loss %)
Extra yarn is ordered to compensate for losses during the dyeing process (default 5%).
7.3 Example (CREAM colour)

[TABLE]
Colour | Count | Ends | REQ KGS | With Dyeing Loss | Rounded
CREAM | 20s | 1,235 | 4.38 | 4.60 | 5 KGS
L.GREY | 20s | 298 | 1.06 | 1.11 | 1 KGS
D.GREY | 20s | 885 | 3.14 | 3.30 | 3 KGS
BLACK | 20s | 546 | 1.94 | 2.04 | 2 KGS
[END TABLE]

8. Weft Yarn Calculation (KGS)
Calculates the weft (filling thread) yarn needed per colour for the full order quantity.
8.1 Weft Ends Calculation
Weft Ends = Onloom Pick x (Reed Space + 3 inches selvage)
3 inches is added as selvage allowance on both sides of the fabric.
8.2 KGS per Colour
Total per colour = (Colour Ends / Total Weft Ends) x Total Weft Length
Dyeing loss is then added in the same way as warp yarn:
With Dyeing Loss KGS = REQ KGS / (1 - Dyeing Loss %)
8.3 Example

[TABLE]
Colour | Count | Weft Ends | REQ KGS | With Dyeing Loss | Rounded
CREAM | 20s | 70 | 4.69 | 4.93 | 5 KGS
L.GREY | 20s | 14 | 0.94 | 0.99 | 1 KGS
D.GREY | 20s | 48 | 3.22 | 3.38 | 3 KGS
BLACK | 20s | 30 | 2.01 | 2.11 | 2 KGS
[END TABLE]

10. Weaving Crimp & Processing Shrinkage
These calculations track fabric dimensional changes through the entire production process.
10.1 Weaving Crimp %
Measures fabric length loss during the actual weaving process.
Weaving Crimp % = (Warp Mtr - Weav Mtr) / Warp Mtr x 100
10.2 Processing Shrinkage %
Measures fabric length loss during wet processing (washing, finishing).
Processing Shrinkage % = (Grey Mtr - Processed Mtr) / Grey Mtr x 100
10.3 Example Values

[TABLE]
Stage | Metres | Loss
Grey (after weaving) | 3,689.7 mtr | -
Processed (after finishing) | 3,364.2 mtr | 325.5 mtr
Processing Shrinkage % | - | 8.82%
[END TABLE]

11. GSM and GLM Calculation
GSM (Grams per Square Metre) and GLM (Grams per Linear Metre) measure the weight of the fabric.
11.1 GSM Formula
GSM = ((EPI / Warp Count) + (PPI / Weft Count)) x 25.4
Where:
EPI = Ends Per Inch (warp thread density)
PPI = Picks Per Inch (weft thread density)
25.4 = Conversion factor for metric system
11.2 GLM Formula
GLM = GSM x (Fabric Width / 39.37)
GLM gives the weight of one metre length of fabric at the full fabric width.
12. GST Calculation (Sheet 2)
Calculates Indian Goods & Services Tax for textile invoicing.

[TABLE]
GST Type | Applicability | Rate | Components
Intra-State GST | Within same state | 5% total | SGST 2.5% + CGST 2.5%
Inter-State GST | Between states | 18% | IGST 18%
[END TABLE]

SGST = Taxable Value x 2.5%
CGST = Taxable Value x 2.5%
IGST = Taxable Value x 18%
Grand Total = Taxable Value + Tax Amount
13. Resultant Count Calculation
When yarn is plied (twisted together), the resultant count determines the effective yarn thickness.
Resultant Count = Single Yarn Count / Number of Plies

[TABLE]
Yarn | Single Count | Plies | Resultant Count
2/60s | 60s | 2 | 30s
2/40s | 40s | 2 | 20s
[END TABLE]
